1. DIAGNOSTIC TROUBLE CODES (DTC’S) USED 
 
The following DTCs are supported for the Altairnano Battery Management Unit (BMU 000-090-0065). 
1.1 
FC101_EXTERNAL_ESTOP_FAULT 
The application has requested an emergency-stop. 
DTC Parameter 
n/a 
DTC Accommodation Level 
E-Stop 
DTC Clearing 
Auto-Clear 
Source 
Application Controller 
Description 
Data 3 or Command Bit Map in Application Command message, 
bit 0 = “External E-Stop”.  If set to ‘1’, the BMU shall perform its 
emergency stop procedure, including setting the “External E-
Stop” bit in the DTC message, the same as if a Level 4 DTC was 
detected. 
Configurable 
No 
Configuration  Option 
None 
 
1.2 
FC103_COMM_TIMEOUT_APP_BUS 
Communication is lost with the application controller.  This communication could be over the external CAN 
bus or on MODBUS RS-485. 
DTC Parameter 
n/a 
DTC Accommodation Level 
Disconnect 
DTC Clearing 
Auto-Clear 
Source 
Application Controller 
Description 
If the BMU does not receive the Application Command Message 
for a period set by C_App_CAN_Timeout_Logic, it shall activate 
a disconnect DTC. (2 seconds is default) 
Configurable 
Yes 
Configuration  Option 
1 sec, 2 sec, or 4 sec

LMU ID

BMU

Configurable  
No 
Configuration  Option

1.15 FC116_CHARGE_CURRENT_ABOVE_CMD_LIMIT 
Charge current is greater than C_Current_Limit_Cmd_Threshold parameter. Default is 103% of 
C_Current_Max parameter.  This happens when charge device is not respecting BMU current limit published 
on CAN bus. 
DTC Parameter 
Current measurement 
DTC Accommodation Level 
Warning 
DTC Clearing 
Auto-Clear 
Source 
BMU 
Description 
The charge current is above the BMS’ charge current 
limit for a period of time. This indicates the Application 
Control Unit is not respecting the limits set by the BMS. 
Hence, if this occurs there is a coordination problem 
between the BMS and the Application Control Unit. 
Configurable 
Yes 
Configuration  Option 
C_Overcurrent_Protection_Enable and 
C_Current_Limit_Cmd_Threshold

1.33 FC148_CONTACTOR_STATUS_MISMATCH 
The sensed status of a contactor differs from its commanded status. 
NOTE:  Parameters for FC148_CONTACTOR_STATUS_MISMATCH are: 
0 = Main positive commanded open, but sensed closed 
1 = Main positive commanded closed, but sensed open 
2 = Main negative commanded open, but sensed closed
